TRAVOR TRENDS WEBSITE — QUICK GUIDE

DEPLOY (Netlify):
 1. Go to app.netlify.com -> your site -> Deploys.
 2. Unzip this file, then drag the whole "travor-trends" FOLDER into the drop box.
 Done. (Or: Add new site -> Deploy manually -> drop the folder.)

CHANGE THE WHATSAPP NUMBER / LOCATION / HOURS:
 Open config.js in any text editor, edit the lines marked "CHANGE THIS", save, re-deploy.

ADD / REMOVE A PRODUCT:
 Open products.js. Copy one product block, change the name, note and image file name.
 Put the new photo in the "images" folder. Set price (e.g. 45000) or leave 0 for "Ask for price".
